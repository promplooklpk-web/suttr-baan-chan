# สูตรบ้านฉัน

แอปมือถือเก็บสูตรอาหารไทยที่บ้าน ไม่ต้องล็อกอิน เก็บข้อมูลในเครื่อง (สูตรเป็น `recipes.json` และรูปในโฟลเดอร์ `images/`)

## สแตก

- Expo SDK 57 · React Native 0.86 · React 19.2
- Expo Router · TypeScript
- ฟอนต์ Sarabun · สีหลักส้ม `#FF7A3D` พื้นครีม `#FFF7EC`

## วิธีรัน

```bash
npm install
npx expo start
```

สแกน QR ด้วย **Expo Go** (SDK 57) บนมือถือ หรือกด `a` / `i` ในเทอร์มินัลสำหรับ Android / iOS Simulator

## ฟีเจอร์

### รอบที่ 1

- หน้าแรก: รายการสูตร การ์ด หมวดหมู่ แถวสูตรโปรด สถานะว่าง
- รายละเอียดสูตร: ส่วนผสม / วิธีทำ / โน้ต ปรับจำนวนเสิร์ฟ โปรด
- เพิ่มและแก้ไขสูตร: ชื่อ รูป ส่วนผสม ขั้นตอน เวลา จำนวนเสิร์ฟ แท็ก โน้ต
- ค้นหา: จากชื่อสูตร ส่วนผสม หรือแท็ก
- แถบนำทางด้านล่างแบบกระจก (expo-blur)
- สูตรตัวอย่าง **20 เมนู** (`seedVersion` 3): 10 อาหารคลีน + 10 จานเดียว (อัปเกรดอัตโนมัติจาก v1/v2 โดยเก็บสูตรที่ผู้ใช้สร้างเอง)

### รอบที่ 2 — ส่งออก / นำเข้า

- ส่งออกทั้งหมดหรือเลือกสูตรเป็น **`.zip`** (`recipes.json` + โฟลเดอร์ `images/`, JSZip) หรือ **`.recipe.json`** (รูปฝัง base64)
- แชร์ไฟล์ด้วย `expo-sharing`
- นำเข้าจาก `.zip` / `.recipe.json` ด้วย `expo-document-picker` ตรวจสคีมาตาม `docs/recipe-export-schema.json`
- หน้าตัวอย่างก่อนนำเข้า และจัดการรายการซ้ำ: **ข้าม / เก็บทั้งคู่ / แทนที่**
- ทางเข้าใน **ตั้งค่า** และหน้า **เลือกสูตรเพื่อส่งออก**

### รอบที่ 3 — โหมดทำอาหารและแท็ก

- **โหมดทำอาหาร** แบบเต็มจอ: ขั้นตอนใหญ่ ถัดไป/ก่อนหน้า รายการเช็คส่วนผสม ปรับจำนวนเสิร์ฟ
- จอไม่ดับระหว่างทำ (`expo-keep-awake`) ตัวจับเวลาต่อขั้น พร้อม haptic เมื่อหมดเวลา (ตามที่ Expo Go รองรับ)
- **จัดการแท็ก** (เพิ่ม/แก้/ลบ) กรองค้นหาตามแท็กและสูตรโปรด

### รอบที่ 4 — แพลนมื้อ รายการซื้อของ สุ่มเมนู

- **แพลนมื้อสัปดาห์**: มอบหมายสูตรให้เช้า / กลางวัน / เย็น เลื่อนสัปดาห์
- **รายการซื้อของ** สร้างจากสูตรในแพลน รวมส่วนผสมซ้ำ เช็คออกได้
- **วันนี้กินอะไรดี?** แท็บสุ่มเมนู + การ์ดโปรโมในหน้าแรก (รูปหน้าปกสูตร) กรองหมวด/เวลา/แคลอรี มื้อเช้า–กลางวัน–เย็น สถานะสุ่ม ผลลัพธ์พร้อมแผนวันนี้และตัวเลือกสำรอง ไม่ซ้ำภายใน 3 วัน (`picker-history.json`)
- **ตั้งค่า**: สำรอง/กู้คืน ล้างข้อมูลทั้งหมด (ยืนยัน) เกี่ยวกับและเครดิตรูปตัวอย่าง

## ลิขสิทธิ์รูปภาพสูตรตัวอย่าง

รูปในแพ็ก seed มาจาก Wikimedia Commons และแหล่งอื่น ภายใต้สัญญาอนุญาตเช่น **CC0**, **CC BY 2.0**, **CC BY-SA 2.0** และ **CC BY-SA 4.0** (รายละเอียดใน `assets/seed/onedish/ATTRIBUTION.md`) แอปแสดงเครดิต สัญญาอนุญาต และลิงก์แหล่งรูปทั้งรูปหน้าปกและรูปแต่ละขั้นตอนในหน้ารายละเอียดสูตร การนำรูปไปใช้หรือแชร์ต่อต้องปฏิบัติตามสัญญาอนุญาตของแต่ละภาพ (โดยเฉพาะ CC BY / CC BY-SA ต้องระบุเครดิตและสัญญาอนุญาต)

## โครงสร้างข้อมูล

- สูตร: `recipes.json` ตามสคีมาใน `docs/recipe-export-schema.json` (schemaVersion 1, app `baan-chan-recipes`)
- แพลนมื้อ: `meal-plan.json` · รายการซื้อของ: `shopping-list.json` (ใน `documentDirectory` ของแอป)
